# 部署指南：家用电脑跑服务 + 阿里云 ECS 中转

> **现状说明（2026-11-25）**：本文是 11-22 首次上线时的方案，隧道由 Windows 侧的脚本和计划任务负责。
> 11-23 晚起，反向隧道改由服务器电脑上的 WSL 用 autossh 发起（Windows 上已没有 ssh.exe 进程），
> 管理入口改为「公网 2222 → WSL → Windows」。这部分配置在服务器上，不在本仓库里；
> 本目录的 `tunnel.ps1`、`tunnel-hidden.vbs` 已不是现行方案。
> 日常发布与回滚请用 `publish.sh` / `rollback.sh`，完整的现行运维说明见《项目交接文档》§0。下文其余内容仅作首次部署的参考。

## 架构

```
浏览器 ──HTTP──> 阿里云ECS nginx(:80) ──> 127.0.0.1:4173(隧道口)
                                                │ SSH 反向隧道（加密）
                                                v
                                    家用电脑 vite preview(:4173)
                                    静态站点 + /api/* 实时数据接口
```

- 家用电脑**主动向外**建 SSH 隧道，路由器无需端口映射、公网无需暴露家里任何端口。
- 隧道断线自动重连（`tunnel.ps1` 循环 + 心跳保活）。
- 外网访问地址：`http://<阿里云公网IP>/`（无需域名、无需备案）。

## 一、家用电脑（服务器）准备

1. 安装 **Node.js 22 LTS**：<https://nodejs.org>（勾选默认即可）。
2. 把整个项目文件夹拷过去（U 盘/网盘均可）。**不需要** `node_modules`、`农田照片/`、`文旅非遗/`（运行时只依赖 `public/` 与构建产物，程序会自动 `npm install` + 构建）。建议放到如 `C:\doumen-smart-farm`。
3. 把阿里云**私钥文件**拷到 `C:\Users\<用户名>\.ssh\aliyun-doumen.pem`（没有就建 `.ssh` 文件夹）。
4. 编辑 `deploy\tunnel.ps1` 顶部的 `$EcsIp` / `$EcsUser` / `$KeyFile` 三项。
5. 首次手动验证（在项目根目录开 CMD）：
   ```
   deploy\start-server.bat          # 另开一个窗口保持运行
   wscript deploy\tunnel-hidden.vbs # 再开一个，后台建隧道
   ```
   本机浏览器开 `http://127.0.0.1:4173` 应能看到大屏。
6. 确认无误后，**右键“以管理员身份运行”** `deploy\install-autostart.bat`：
   注册 `doumen-server`、`doumen-tunnel` 两个计划任务（登录自启）并立即启动。
   - 家用电脑需设置**不休眠**（设置→系统→电源→屏幕可关、睡眠设“从不”），并保持开机。

## 二、阿里云 ECS（中转）配置

以下操作可从任意能 SSH 的电脑执行（已由助手完成则跳过）：

1. 安装 nginx 并放入配置：
   ```bash
   # Alibaba Cloud Linux / CentOS:
   yum install -y nginx
   # Ubuntu/Debian:
   # apt update && apt install -y nginx
   ```
2. 将 `deploy/aliyun-doumen.conf` 上传为 `/etc/nginx/conf.d/doumen.conf`，
   删除或清空 `/etc/nginx/conf.d/default.conf`（避免 80 端口冲突）。
3. `nginx -t && systemctl enable --now nginx`。
4. **安全组**（阿里云控制台→ECS→安全组→入方向）放行：
   - `80/80`  来源 `0.0.0.0/0`（对外访问）
   - `22/22`  来源仅自己的 IP（SSH 管理）
   > 隧道端口 4173 只绑在 ECS 的 127.0.0.1 上，**不要**在安全组开放 4173。

## 三、日常使用

| 场景 | 操作 |
|---|---|
| 开机后自动上线 | 无需操作（计划任务登录自启） |
| 外网访问 | `http://<阿里云公网IP>/` |
| 查看隧道状态 | 任务管理器找 `ssh.exe`；或 `tasklist \| findstr ssh` |
| 重启隧道 | `taskkill /f /im ssh.exe` 后重跑 `tunnel-hidden.vbs`（5 秒内自动重连） |
| 更新代码 | 在家用电脑项目目录 `git pull`（或覆盖文件）→ 删 `dist` → 重跑 `start-server.bat` |

## 常见问题

- **打不开页面**：顺序排查 ① 家里 `127.0.0.1:4173` 通不通（不通=服务没起来）② ECS 上 `curl 127.0.0.1:4173` 通不通（不通=隧道断了）③ 外网 `curl http://IP/`（不通=安全组/nginx）。
- **隧道频繁断**：家用电脑网络不稳属正常，脚本会 5 秒重连；连续失败检查 ECS 磁盘/密钥路径。
- **数据不刷新**：接口有缓存周期（天气 15 分钟/预警 5 分钟），且依赖家里电脑能访问外网数据源。
- 若 ECS 换 IP / 换密钥：改 `tunnel.ps1` 顶部配置后重启隧道任务即可。
